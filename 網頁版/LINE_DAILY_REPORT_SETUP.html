每日 LINE 統計自動傳送設定

作用

每天台灣時間晚上 21:00，由 GitHub Actions 自動讀取當天區間統計，並透過 LINE Messaging API 傳送給店長。

GitHub 需要設定的保密資料

到 GitHub 專案頁面設定以下兩個 Secrets：

  • LINE_CHANNEL_ACCESS_TOKEN：LINE 官方帳號 Messaging API 的 Channel access token
  • LINE_TO_ID：店長的 LINE user ID，或店長所在群組的 group ID

取得 LINE_TO_ID

店長需要先加 LINE 官方帳號為好友，或把官方帳號加入指定群組。

取得 user ID / group ID 的方式要透過 LINE 官方帳號 Webhook 接收事件；收到店長傳訊息或群組訊息後，事件內容會帶 source.userId 或 source.groupId。

手動補送

到 GitHub 專案的 Actions 頁面，選擇 Daily LINE report，按手動執行；日期留空會送今天，填日期則會補送指定日期。

本機測試

可用測試模式先確認訊息內容。測試模式只會讀報表並印出 LINE 文字，不會真的傳送。

PowerShell 範例：

$env:LINE_CHANNEL_ACCESS_TOKEN='test'
$env:LINE_TO_ID='test'
$env:REPORT_DATE='2026-07-04'
$env:DRY_RUN='1'
node .\scripts\send-daily-line-report.mjs

注意

LINE Notify 已於 2025-03-31 結束服務，所以本功能使用 LINE 官方帳號的 Messaging API。
